# Building HexedVoiceMod

The build instructions live in the README: see **"Build on GitHub"** and **"Local build"** in [README.md](README.md#build-on-github).

Short version: push the project to GitHub, let the `build-hexedvoicemod` workflow run, download the `HexedVoiceMod` artifact (`libHexedVoiceMod.so`). The workflow downloads RubberBand and RNNoise itself; they are not stored in the repository.
